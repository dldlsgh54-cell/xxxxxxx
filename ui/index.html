분석 결과가 여기에 표시됩니다

요일과 시간대별 반응, 계정별 게시 빈도, 쿠팡 링크 위치를 비교할 수 있습니다.

분석 기준과 데이터 출처

한국 시간으로 4시간 단위로 묶습니다. 반응 수는 좋아요·답글·리포스트·인용의 합계입니다. 게시 후 48시간이 지난 글의 성과를 비교하고, 노출 데이터가 충분하면 반응률을 사용합니다. 반응 점수는 같은 계정 안에서의 백분위이며, 계정별 중앙값을 같은 비중으로 합칩니다. 50점은 계정 내 중간 수준입니다.

쿠팡 링크는 공개 본문과 조회 범위 내 작성자 답글에서 확인합니다. 클릭과 판매 데이터는 집계에 포함되지 않습니다. 시간대 결과는 해당 표본의 관찰값입니다.
